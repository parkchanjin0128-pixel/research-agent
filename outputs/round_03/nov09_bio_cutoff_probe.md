# 바이오 3행의 관측창 확인

2026-11-09 생산 메모, `/root/nov9_cutoff_probe`. 원격 입력 `99979a91f55979cfb5c1587e91e8ee69fd9f7585`의 [바이오 3행 근거표](regulatory_audit_rows_nov09.md)와 C017–C028의 확인 범위를 사용했다. 아래 새 원문 대조와 적용 판단은 독립 검증 대기다.

각 행에서 첫 판정을 내리는 데 필요한 최소 묶음은 **품목·소프트웨어·기술과 EAR 적용성, 거래 방향·당사자·최종용도, 발주·선적일과 적용된 허가·예외, 해당 규칙의 개정 전후 문언·효력일·경과규정**이다. 먼저 2018년 11–12월의 관련 조치와 창 전 공표·창 내 효력 규칙을 2019년 1–4월 원규칙과 이어 붙인 뒤, 확인된 거래에 4월 UVL 변경을 대조한다. 월 중 순증 제한이 확인되면 그 월부터 해당 거래의 완전월 후보에서 제외한다. 특정 거래 하나의 결과가 행 전체 또는 다른 행의 판정으로 이어지려면 표본 범위에 대한 별도 증거가 필요하다.

접근 한계로 이번 조회에서 2019판 Part 742와 China CB2 셀을 직접 확보하지 못했다. 기존 C022·C026이 검증한 CB1/AT1로 대체하지 않았다. 41행 규제 상태 판정에 추가할 근거는 확보되지 않았다.
