# 2026-11-12 추가 검증: 결과 확인 전 분석 순서 기록

사용자의 11월 12일 직접 지시에 따른 탐색 분석이다. 원 연구의 사전등록·주설계 채택 또는 Gate 통과를 뜻하지 않는다. 2013–2017 인용 dose와 표본 커버리지는 이미 관측했다. 아래 월별 2018–2019 outcome은 이 기록 작성 시 확인하지 않았다.

1. 먼저 TLS207 신청인 주소와 TLS227 공개공보 신청인 주소의 국가 커버리지를 같은 필터로 비교한다. 공개관청 CN을 중국 출원인으로 치환하지 않는다. 국가 주소가 확인된 표본에 대한 결과와 모집단 일반화를 구분한다.
2. 고정 기술은 앞선 파일럿과 동일한 C12N, G01S, G06F, G06N, H01L이다. 임의로 고른 5개 기술이며 ANPRM 지정/비지정의 검증된 crosswalk가 아니다. 국가 주소 CN, US, JP, KR, DE를 각각 집계한다. 복수 국가 공동출원은 국가별 중복 허용, 전체 국가 총합으로 해석하지 않는다.
3. PI 발명, 양의 DOCDB family, earliest filing 2013-01–2019-12, earliest publication <=2021-12-31을 사용한다. 현재 PATSTAT 판본의 회고적 분류·주소라는 한계를 기록한다. family를 class·국가별 중복 제거하며 family 내 최소 earliest filing 월을 사용한다. TLS207 기준을 기본, TLS227은 커버리지 검사의 대안으로 별도 보존한다.
4. 0 관측도 월별 전체 격자에 채운다. outcome은 log(1+family count). 기본 상대 outcome은 CN minus US/JP/KR/DE의 동일 가중 평균이다. 대조국은 파급효과가 없다고 입증되지 않았으므로 인과적 무처치군으로 간주하지 않는다.
5. B는 기존 2013–2017 전체 기원 인용의 미국 비중(known-country 분모)으로 고정한다. APP 기준은 측정 민감도 분석이다. 인용 비중은 효과 수정변수이며 정책 처치 dose와 동일하다고 가정하지 않는다.
6. 먼저 2013–2017 국가·기술별 추세와 dose별 선행 추세를 보고한다. 이후 월별 상대 outcome의 B 기울기를 2017년 평균 기준으로 계산한다. 사전 지정 요약창은 2018-12–2019-04이며 이는 규제 감사 전의 후보창이다. 이전 ZTE·관세·Jinhua 등 실제 제한 및 중국 정책이 제거되었다고 주장하지 않는다.
7. 5개 기술의 표본이 작고 선택적이므로 유의성에 의한 인과 결론을 내리지 않는다. 기술 하나씩 제외, 대조국 하나씩 사용, B의 ALL/APP 정의를 모두 보고한다. 별도 유효한 배정기제가 없는 B 순열은 randomization inference로 부르지 않는다. 결과를 본 뒤 유리한 방법·표본·날짜를 주결과로 승격하지 않는다.
8. 데이터 접근이 성공하면 실제 계수·선행 추세·표본 수를 계산한다. 커버리지 또는 선행 추세가 실패하면 실패 자체를 기록하고 더 큰 사전 고정 표본/새 자료가 필요한 이유를 수치로 제시한다. 이 분석은 특허 활동의 진단이며 연구자금·신청·투자 재배분을 직접 측정하지 않는다.

## 커버리지 확인 후·월별 결과 확인 전 수정

TLS207/TLS227 비교에서 CN 관청 378,397 applications 중 주소국가 확인은 각각 10/29개, CN 주소 확인은 각 1개였다. JP도 거의 비어 있었다. 반면 WO는 102,710개 중 각각 102,596/102,598개의 주소국가가 확인되었다. 이는 본 쿼리·판본·필터에 대한 관측이며 국가 전체 특허 품질에 관한 일반 명제가 아니다.

이에 월별 outcome을 **WO 관청 PCT 출원을 가진 국제 특허 family의 신규 출원 활동**으로 한정한다. TLS207의 WO application 신청인 국가 주소를 쓰고, 동일 family·IPC class·국가를 중복 제거한다. WO application 중 최소 earliest filing date로 월을 정한다. 목표를 국내 연구배분의 직접 검정으로 바꾸지 않으며, 사전 dose는 기존 파일럿의 ALL/APP 두 측정을 그대로 유지한다. 동일 모집단의 dose로 재집계하지 않았다는 불일치도 한계다. 이 변경은 국가 커버리지 관측을 보고 정했으며 2018–2019의 월별 활동 결과는 아직 열람하지 않았다.
