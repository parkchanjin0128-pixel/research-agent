# 미국의 규제 예고와 중국의 기술 대응

2026년 11월 14일 연구논문·학술발표 작업본이다. 기존 연구질문을 유지하면서, 사용자가 허용한 트럼프 2기 발표 사례를 실제 일별·시간별 자료로 추가했다. 연구 자동 실행은 중지 상태로 유지한다.

## 제출용 파일

- `manuscript/규제예고와_중국의_기술대응_논문.pdf`: 초록, 제도, 선행연구, 이론, 데이터, 식별식, 실제 결과, 강건성 분석, 결론, 부록, 참고문헌.
- `manuscript/논문.md`: 수정 가능한 논문 원고.
- `presentation/deliverables/학술발표_2026-11-14_v4.pptx`: 본문 32장과 부록 8장. 수식, 편집 가능한 표 13개와 데이터 차트 7개, 발표자 노트 포함.
- `presentation/발표대본.md`, `presentation/발표목차.md`: 권장 시간배분 포함. 리허설을 실제 측정한 시간은 아니다.

## 실제 확보한 새 증거

2025년 10월 10일 10:57 EDT의 선행 대중 보복·관세 위협을 포함한 10:30–11:30에 중국 ADR 4기업 포트폴리오 수익률은 -5.089%, S&P500 시장모형 조정 반응은 -4.034%였다. KWEB와 MCHI의 시장조정 반응도 각각 -4.022%, -3.215%다. 주창의 시장모형 적합은 과거 같은 시각의 59–60거래일이다. 관세·핵심 소프트웨어 통제의 구체적인 추가 예고는 16:50 EDT의 장후 발언이다. 정규장 결과를 그 소프트웨어 문구의 단독 효과로 부르지 않는다.

벤치마크를 중국 ETF로 바꾸면 4ADR의 상대반응은 양수다. 이는 영향받는 중국자산을 조건으로 한 별도 대조이며, 안전한 통제변수 추가나 기술통제 효과의 분리가 아니다. 기존 2013–2017년 특허 의존도 기울기는 기업 하나 제외에 따라 부호가 바뀐다. 가격하락은 자체 연구개발 증가의 증거와 구분한다. 논문의 단순 모형은 대체재와 보완재 조건에 따라 연구투자 방향이 달라짐을 보인다.

2018년에는 최초공보 국가를 적용한 18기술 × 5국 × 120개월의 10,800셀을 새로 집계했다. 양수 4,085셀, family 소속 합계 32,330이며 세계 고유발명의 수가 아니다. 미국 인용 지표의 지목·비지목 공통 점범위가 없고, 대체 지표의 공통 범위 표본에서도 큰 사전 변화가 남는다. 원래 연구배분 인과효과를 통과로 판정하지 않는다.

## 분석의 지위

탐색적 연구논문 작업본이다. 새 일별 후보는 새 일별 결과를 보기 전에 기록했지만, 시간별 추가분석은 일별 결과를 본 뒤 설계했다. 다른 후보의 결과와 부적합했던 비교를 삭제하지 않았다. 표준화 예측오차, 과거 잔차 순위, dose 재배정 기준비교와 조건부 MDE를 정책배정에 대한 인과 p값·정책효과 신뢰구간으로 제시하지 않는다.

WIPO 분류와 2018년 시장자료에는 각각 별도 작성자의 독립 검증보고서가 있다. PATSTAT 별도 쿼리의 좁은 재조회 결과도 보존했다. 그러나 새 최초공보 패널·2025년 분석·전체 새 논문에 대한 최종 독립 심사는 완료되지 않았다. 추가 검증 에이전트가 구독 사용 한도에 도달하여 중단됐으며 유료 API나 크레딧으로 우회하지 않았다. 작성자의 산술 검산을 독립 검증으로 표시하지 않는다. 과거 Gate 실패와 SCI01–05는 유지한다.

## 재현자료

- `crosswalk/`: 같은 공식 분류 절차를 거친 지목·비지목 연결, exact membership, 분석단위 합집합.
- `patstat/`: 실행쿼리, 원집계 JSON, 최초공보 국가 패널, 서비스 메타데이터. 데이터셋 이름으로 PATSTAT 배포판을 확정하지 않는다.
- `market/`: 2018년 일별 가격·CAR·시점변환·기업경계·실적 중첩.
- `trump2/`: 2025년 일별 가격과 후보 전체 결과, 시간별 OHLC, 같은 시각 잔차, 비교 벤치마크, 별도 산식검산, 시간외 quote-only 표.
- `analysis/`: 새 기술 패널의 관측대조, 지원·위약시점·MDE 진단과 논문 그림.
- `verification/`: 독립 검증의 확인 범위와 미완료 부분.

재계산은 `market/compute_car.py`, `patstat/analyze_new_panel.py`, `trump2/hourly_analysis.py`, `trump2/extend_and_recheck.py`, `presentation/make_evidence.py`의 순서와 각 protocol을 따른다. 다운로드를 재실행하면 공급자의 수정가격이 달라질 수 있으므로 보존 원자료를 먼저 사용한다. EPO 원쿼리의 개행 정규화 해시와 Windows 파일 바이트 해시는 구분한다. 로그인 정보·세션 토큰·사용자 제공 논문 전문은 패키지에 포함하지 않는다.

## 후속 검증의 과학적 우선순위

1. 새 가격 분석과 최초공보 국가 패널을 작성자가 다른 검증자가 독립 재현하고 사건창의 동시 뉴스를 추가 점검한다.
2. 2025년 분석에서 2024년 말 기준 실제 소프트웨어·장비 의존도, 미국 매출 노출, 기업경계를 분리한다. 오래된 특허 B를 현재 실제 손실로 바꾸어 부르지 않는다.
3. 장기 연구배분은 전체 신청 또는 결정이 확정된 투자·연구계획의 시점자료로 검증한다. 현재 가격자료로 방향을 대신 입증하지 않는다.

이 우선순위는 결과를 기다리며 중단하라는 뜻이 아니다. 지금까지 가능한 공개자료 검증과 실제 추정을 수행했고, 무엇을 더 관측해야 명제가 구분되는지를 특정한 것이다. 작업본을 학술지 게재가 보장된 완결 인과논문으로 표시하지 않는다.
