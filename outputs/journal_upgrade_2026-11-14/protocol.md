# 최종 심사 미달 항목의 실제 실증 보완

2026-11-14 한국시간, 최신 직접 사용자 지시: 탑저널 수준에 부족한 부분을 계속 연구해 완성한다. 기존 예약중지·구독 Sol Extra High 이하·무과금·동일 연구질문을 유지한다. 기존보고서·심사·원자료는 덮어쓰지 않는다. 새로운 Gate나 불가역 freeze는 채택하지 않는다.

기존 WO5국×5IPC×84월 및24그룹 국가정보 실험의 결과를 이미 읽었다. 아래는 추가 탐색이며 사전등록/독립확증으로 소급하지 않는다. 새 비교기술의 결과를 보기 전에 이 기록과 별도분류·시장 protocol을 저장한다.

## 이번에 실제로 수행할 것

1. 2017 IPC 공식 의미 및2018 ANPRM 원문으로 좁게 지목된 기술과 비지목 후보를 같은 계층·동일 코드pipeline에서 분류한다. 모호·다의적 집단은 분류 미확인으로 둔다. 비지목은 다른 정책의 미노출 또는 법률상 미통제와 같지 않다. raw family의 양 팔 중첩·재분류·국가분모를 진단한다.
2. 신호 전2013–2017에 **공개된** source WO 문헌의 중국 주소 출원인 family에서 인용 노출을 집계한다. 기존 필링코호트2017에 공개기한2017을 겹쳐 강제절단한 표본과 구별한다. APP 전용과 ALL은 각각 대표공보·분모를 명시하고 미상·pair0를0으로 변환하지 않는다. 추가로 IP5계열 국가비중의 정의·관측가능성도 점검한다.
3. 비교 기술 지원은 새 post2017 결과를 사용하지 않고 성숙 사전2010–2015 필링 cohort의 지원으로 진단한다. 정책·비교국 파급과 B 측정 타당성을 조건화하지 않은 점추정은 관측대조로만 부른다. 사전추세·가짜시점·유사B공통지지·기술중첩을 실제계산한다. listed/nonlisted 차이와 국가placebo를 혼동하지 않는다.
4. 중국기업의2017–2019 실제 일간 주가·벤치마크 접근을 먼저 시험한다. 기업·시장·모형·사건창을 가격 열람 전 별도문서에 정한다. 의존도는 기업의 사전 법인/특허에서 새로 계산한다. 배분 결과를 본 뒤 CAR가중치를 사전고정했다고 쓰지 않는다. 시장반응은 배분효과가 아닌 보강정보로만 쓴다.
5. 규제표의 미확인을 넓은 범주의 미통제확인으로 올리지 않는다. 품목/정보의 정확한 사양·당시규칙·최종사용자/거래·시점에 관해 확인 가능한 좁은 명제만 새로 판정한다. 전수기술 분류와 실제 거래의 접근차단을 구별한다.

## 기존 지적과 보완 범위

SCI01–05와 PCX02의 기존 이력/중대성을 보존한다. 최신직접지시를 필요한 가역적 코드 보완과 새 독립 재검증의 승인으로 받아들이되, 세 번째 수정이나 새 단위 이름으로 과거 판정을 지우지 않는다. 최종효과의 채택·질문변경·불가역설계 freeze는 하지 않는다. 코드의 실제 실패는 실패로 보고하고 새 데이터·배제제약 없이 방법명 추가로 인과성을 주장하지 않는다.

생산자와 다른 새 verifier 및 referee가 현재 원문/자료/코드·해시를 확인한다. 모든 결과·접근실패·탈락이유를 보존한다. 적어도8분 단위로 로컬 checkpoint, 통합시 원격 expected-head 조건부 저장·재조회를 수행한다. 자동 예약은 재개하지 않는다.
