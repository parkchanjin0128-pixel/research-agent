# 최종 연구의 실행 및 완료 기준

2026-11-12 최신 직접 지시: 연구·최종 보고서·30분 이상 발표자료·대본을 완성할 때까지 계속 진행한다. 질문은 미국의 공식 신호 자체가 실제 제한 전에 중국의 연구·자본 배분을 바꾸는가다. 기존 Gate2·3 실패, charter, 기존 심사 이력과 사용자 결정 대기를 보존한다. 새 탐색자료를 읽고 있으므로 사전등록·확인분석으로 소급하지 않는다.

실행 순서:

1. **측정**: 공개 특허지식과 통제되는 기술접근의 제도적 차이를 감사한다. 인용 dose의 신청인 국가누락을 같은 target family의 사전 공개 공보로 보완하는 별도 proxy를 계산한다. 이를 원래 신청인의 누락값에 대한 진실한 대체로 간주하지 않는다. 2017 의미분류와 2019/2020 재분류를 구별한다.
2. **행동자료**: 공개 공식 신청·승인·연구지원·투자 공시의 실제 행을 수집한다. 결정·신청·승인·공개의 시계를 구분한다. 2019 연간 승인자료를 실제 제한 전 신청행동으로 바꾸지 않는다.
3. **실증**: 기존 패널에서 계절구성·국가 placebo·사전 가짜창·예측실패·편향허용의 반증을 실행한다. 5 IPC와 공유 패밀리를 많은 독립 cluster로 세지 않는다. 추가 방법을 유리한 계수를 고르기 위해 사용하지 않는다.
4. **식별 판정**: 효과를 점식별하는 데 필요한 비교·시계·독립변이가 확보되는지 판단한다. 자료로 검증할 수 없는 조건은 가정으로 표시하고 허용 위반별 결론을 보고한다. 실제 제한 전 직접 행동을 관측하지 못하면 ‘announcement 인과효과 입증’을 보고서에서 주장하지 않는다.
5. **통합**: 원문·식별 구조·실증·부분식별/반증·새로운 인사이트를 하나의 보고서와 30분 이상 발표·원고·Q&A로 연결한다. 보고서·PPTX/PDF·대본·재현물의 수치와 상태를 일치시킨다.
6. **독립 검증과 백업**: 생산자와 다른 검증자/심사자가 새로운 사실·주장·최종본을 검토한다. 남은 지적은 지우지 않고 응답·판정을 기록한다. 작은 단위마다 GitHub 조건부 커밋·재조회·로컬 묶음을 저장한다. 자율 목표는 완료될 때까지 active로 유지하며 한도로 중단되면 실제 checkpoint에서 재개한다.

완료 선언은 인과가설이 반드시 지지된다는 뜻이 아니다. 자료·식별·반증으로 어느 결론이 가능한지를 끝까지 평가하고 그 결론에 맞는 최종 산출물과 재현·검증을 갖춘 상태를 말한다. 게재·효과 부호·통계적 유의성은 보장하지 않는다. 질문 변경이나 Gate 채택·불가역 freeze는 별도 결정사항이다.
