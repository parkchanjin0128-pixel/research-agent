# 최종 보고·발표 패키지

2026년 11월 13일. 원 연구질문은 **미국의 기술통제 신호 자체가 실제 접근 제한 전에 중국의 연구·자본 배분을 바꾸는가**다. 현재 자료로 이 인과효과는 식별되지 않았다. 아래 산출물은 실제 자료의 계산·측정·식별 감사 결과이며, 양의 효과를 확인한 논문이나 최초성·게재 승인본은 아니다.

## 실제로 확인한 결과

- 월별 특허 패널은 국가5×IPC5×월84=2,100셀이다. 합계202,110은 국가·분류별 family 소속의 합이며 세계의 고유특허 수가 아니다. 기존 인용 B의 관측투영 대조계수는 ALL −0.0806645, APP −0.0499468이다. B 10%p당 상대 log(1+건수)의 차이이며 R&D 증가율이나 인과효과가 아니다.
- 비교국·기술 하나 제외에 민감하고 2017년 예측오차가 크다. 기존 465개 산술검산과 이번 독립 441개 비교그룹은 계산범위의 확인이며 정책가설 906개를 검정한 것이 아니다. 겹치는 가짜창의 순위는 정책 p값이 아니다.
- 별도24그룹 측정에서 알려진 인용대상 국가 쌍은4,659→6,561, 국가미상 산술경계폭 중앙값은60.9→41.4%p다. 대표공보를 바꾸어 구성개념도 달라졌다. 기존 월별 β를 새 B로 재추정하지 않았다. 경계는 신뢰구간이 아니며 전체 기술순위는 식별되지 않았다.
- 공식 NSFC 승인340행, 서로 다른 MOST 프로그램의 선정예정40행, 조달 품목34행과 대학2곳의 공고 아카이브7,120행을 확보했다. 승인·선정예정·입찰·낙찰·인도·최초 연구결정은 서로 다른 시계다. 이 행들을 독립 과제나 신청 모집단으로 합산하지 않는다.
- 중국2013–2017 수입의 미국 partner 금액비중은 HS8486 14.5582%, HS8542 4.7515%다. 미국 기업·설계·EAR 관할의 비중은 아니다. 2015–2017 12개 행은 UNSD 집계 플래그를 갖는다.
- 2018 EAR 공개특허 기술정보 제외, 2018-10-24 APP 통제문턱 완화, 2019/2020 IPC 개정은 측정과 시점 해석에 직접 중요하다. 이를 개별 거래의 허가 여부나 모든 GPU의 허용으로 확대하지 않는다.

## 검증과 미해결

`verification/`에는 서로 다른 검증자의 계산·측정·공식행동·1차 법규 검증 범위가, `review/`에는 첫 심사와 작성자 응답·수정 재심사가 있다. `literature/pdf_audit.*`는 사용자 제공8파일/7고유문헌의 판본·처치·시점에 대한 원문 집중감사다. 검증 파일의 통과는 원 인과가설의 통과가 아니다. 최종 실제 상태는 [STATUS.json](STATUS.json)을 따른다.

중국의 독자 정책과 미국 신호의 관측동등성, 비교국 파급, 잠재손실 B의 타당성, 최초 배분결정일과 추가 제한일, 작은 유효표본과 실제 추론은 남아 있다. SCI-01~05 및 기존 PCX-02 결정대기를 지우지 않는다. 새 Gate·연구질문 변경·불가역 freeze는 채택하지 않았다.

## 재현·보존

코드는 프로젝트 루트의 `outputs/` 구조를 유지하면 상대경로로 집계를 읽는다. 보존된 집계로 NumPy/표준 Python의 산술을 재계산할 수 있다. EPO 원 DB 독립 재쿼리나 당시 데이터판본을 재현했다는 뜻은 아니다. 정부·대학 웹 원문 전체, 논문 PDF, 큰 WIPO 배포본과 사용자 로컬 경로는 공개 발행물에서 제외한다. 원문 URL·해시와 필요한 발췌·정규화 사실을 보존한다. 공개 발행의 경로 치환·gzip 여부와 원본/발행본 해시는 배포 manifest에서 구분한다. 배포용 자료에 포함되지 않은 웹 원문 재검증은 해당 공식 URL에서 다시 받아야 한다.

후속 수동 작업은 [RESUME.md](RESUME.md)를 읽는다. 원격 저장 성공은 해당 발행 receipt와 재조회가 있을 때만 보고한다. **11월13일 최신 사용자 지시로 연구 예약을 중지했고, 이 세션에서 진행한다.** 웹·로컬 예약은 PAUSED, GitHub Actions 연구 workflow는 disabled_manually다. 새 요청 없이 재활성화하지 않는다. 유료 모델 API·추가 크레딧을 사용하지 않는다.
