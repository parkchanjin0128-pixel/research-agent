# 가족 공보 국가 footprint 및 무역 보조측정 독립 검증

검증일: 2026-11-13. 검증 대상은 보존된 측정 결과의 산술·출처·해석 범위다. **집계 수치는 재현됐으며, 2016년 무역 공개 API 4행도 독립 요청과 일치했다. 특허 원 DB의 SQL은 독립 재실행하지 않았다. 인과식별이 완료됐다는 판정은 아니다.**

## 검증 방법과 자료 동일성

`family_country_recovery_raw.json`의 SHA-256은 `d57a64d28c0199db098077edc7a9cbd7d6c8a91ddb4a526efa4e4252f6099d52`로 지정값과 일치했다. 기존 `finegroup_pre_dose_raw.json`과 선택된 24개 main group 및 기반 스크립트 해시가 일치한다. 새로운 결과의 각 그룹·origin별 pair 수는 기존 결과의 pair 수와 같다. 총 45행은 ALL 24행과 APP 21행이다. 그룹별 합계·중앙값·범위·교집합 및 구간 쌍 비교를 기존 summary를 계산 입력으로 쓰지 않고 다시 계산한 뒤 summary와 대조했다.

무역은 `all_rows.json`의 20행에서 직접 연도별 비중과 합산 비중을 계산했다. 2013–2016년 원응답 및 2017년 pilot 원응답의 바이트 해시는 각각 `history_sources.json`과 `pilot_2017_meta.json`의 해시와 일치했다. 각 원응답은 count=4, 실제 data 4행, error 공란이며, 다섯 원응답을 합친 행은 `all_rows.json`과 일치했다. 입력별 해시와 세부 검산은 동반 JSON에 기록했다.

이는 같은 데이터베이스에서 독립적으로 표본·인용 pair·person 명단을 재구축한 검증과 구분해야 한다. 보존된 특허 그룹 집계에는 개별 pair와 person 명단이 없어, 신청인별 미국분수와 가장 이른 공보 선택을 원자료에서 다시 계산하지 못했다.

### 새 대리변수의 의미와 구간 조건

프로토콜과 보존 SQL tail은 target family마다 2017-12-31까지 공개된 공보 중 신청인 국가가 하나 이상 알려진 가장 이른 공보를 선택한다. 같은 날짜면 공보 ID로 순서를 정한다. 이는 **해당 family의 사전 공개 신청인 국가 footprint라는 새 대리변수**다. 원 피인용 공보의 국가 결측치를 정답으로 복원하거나 대체했다는 주장은 적절하지 않다. 알려진 국가가 있는 공보를 골라야 포함되는 선택이 있고, 공보별 명단·주소·법인이 달라질 수 있다.

보존 SQL의 pair별 분수는 미국 인원 U, 국가 확인 인원 K, 관측 명단 인원 L에 대해 known-only는 U/K, 하한은 U/L, 상한은 (U+L−K)/L이다. L=0이면 [0,1]을 부여하고 그룹 내 pair 평균을 계산한다. known-only는 K>0인 pair에만 조건부다. 이 산식은 SQL tail에서 확인했으나 person 원자료를 다시 조회해 산식을 재현하지는 않았다.

구간은 관측된 신청인 명단의 미상 국가와 선택된 family 공보에 조건부다. 명단 자체 누락, 가족 공보의 선택, 소유권 변경, 주소 오류, 국제출원 선택, 신청인 국가와 실제 기술 공급원의 차이를 포괄하지 않는다. 표본변동을 반영한 신뢰구간도 아니다. 국가 확인률과 폭의 개선만으로 실제 미국 기술 의존도 측정이 타당해졌다고 할 수 없다.

### 공통교집합과 순위

ALL의 공통교집합 계산값은 [0.4225829726, 0.3583740102]이고, APP는 [1,0]이다. 하한의 최댓값이 상한의 최솟값보다 커서 두 교집합 모두 공집합이다. 이는 모든 그룹이 하나의 공통값을 가질 수 없다는 주변구간 진단이다.

**전체 순위가 식별됐다는 뜻은 아니다.** ALL의 276개 그룹 쌍 중 구간이 엄격히 분리된 쌍은 9개이고 267개 쌍은 겹치거나 접한다. APP는 210개 중 162개가 분리되고 48개가 겹치거나 접한다. 이 주변구간만으로 엄격한 순서를 보장할 수 있는 것은 분리된 쌍뿐이며, 공유 family가 만드는 공동 제약은 별도로 재구축하지 않았다.

### 직접 공개 API 대조

검증자가 2026-11-13 02:58:47 UTC에 [2016년 공개 API](https://comtradeapi.un.org/public/v1/preview/C/A/HS?reporterCode=156&period=2016&partnerCode=0%2C842&cmdCode=8486%2C8542&flowCode=M&partner2Code=0&customsCode=C00&motCode=0&maxRecords=4)를 별도로 1회 요청했다. 계정·API 키·유료서비스 없이 maxRecords=4를 지정했고 HTTP 200, count=4, error 공란이었다. 429 응답이나 우회·재시도는 없었다. [공식 API 문서](https://comtradeplus.un.org/en/api-docs)는 public preview가 키 없이 동작하며 최대 500행임을 명시한다.

### 단위·평가·원보고 표시에 관한 해석

[공식 단위 설명](https://uncomtrade.org/docs/conversion-factors-and-current-constant-value/)에 따르면 금액은 경상 미국 달러다. [공식 평가 설명](https://uncomtrade.org/docs/trade-valuation/)과 [필드 정의](https://comtradeplus.un.org/en/reference-tables?table=dataitem)는 primaryValue가 CIF 또는 FOB에서 취해지는 기본 금액임을 설명한다. 여기서는 20행 모두 CIF 금액과 실제로 같다. CIF에는 수입국 국경까지의 운송·보험 관련 가치가 포함된다.

**원보고 분류판과 직접 보고 행은 구분해야 한다.** 20행 모두 `isOriginalClassification=true`이며 2013–2016년 H4에서 2017년 H5로 바뀐다. 그러나 2013–2014년 8행은 `isReported=true, isAggregate=false`, 2015–2017년 12행은 `isReported=false, isAggregate=true`다. 공식 필드 정의상 후자는 UNSD 집계 표시다. 이 사실만으로 거울통계나 추정치라고 추가 단정하지도 않는다. 따라서 모든 20행을 중국이 직접 제출한 원보고 행이라고 부르는 것은 부정확하다. 국가가 보고한 분류판에서 제공되는 중국 reporter 수입 집계라고 표현하는 것이 적절하다. H4→H5의 내용 대응을 독립적으로 완결한 검증은 아니다.

이 비중은 관세통계상의 미국 partner 금액 구성이다. 미국 기업의 제3국 생산과 비미국 기업의 미국 기술 사용, 재수출 경로, 실제 공급자, 개별 장비 사양을 식별하지 않는다. HS4는 ECCN이 아니며 미국 partner 비중은 미국 기업 국적·FDPR 관할·미국 기술 의존도와 동일하지 않다. 이 보조측정과 새 특허 대리변수 모두 탐색적 측정 진단으로 사용할 수 있으나, 해당 결과만으로 제재 범위나 정책효과를 확인했다고 해석해서는 안 된다.
