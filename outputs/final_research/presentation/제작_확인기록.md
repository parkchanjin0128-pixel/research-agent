# 발표자료 제작·확인 기록

최종 파일은 deliverables/최종_연구발표.pptx와 같은 이름의 PDF다. 본문 32장과 부록 6장, 본문 권장시간 38분45초.

- 기존 35장 자료를 읽고 최종 실제 결과로 내용을 다시 구성했다.
- 38장 전체를 Artifact Tool로 1280×720 PNG 렌더링해 개별 확인했다. 텍스트·차트·축·분모·각주에서 넘침과 의도하지 않은 겹침을 발견하지 않았다.
- 최종 패키지 검증은 슬라이드38, native chart7, 레이아웃·패키지 finding0, Artifact Tool 재import 통과를 확인했다. 각 차트에는 편집 가능한 데이터 workbook을 포함했다.
- 차트 snapshot은 원자료의 표시용 반올림 값이며 원데이터와 수식의 보존을 주장하지 않는다. 원 집계·정밀 수치는 동봉 재현자료와 근거표를 따른다.
- PowerPoint COM이 최종 PPTX를 읽기전용으로 열어 38페이지 native PDF를 내보냈다. 화면에서 직접 PowerPoint 슬라이드를 검사했다는 뜻은 아니다.
- Artifact Tool 자체 PDF 내보내기는 bundled dependency #standard-fonts/Helvetica 누락으로 실패했다. PowerPoint의 PDF 출력으로 완성했으므로 최종 PDF는 래스터 대체본이 아니다.
- 기존 독립 산술465항목과 신규441개 비교그룹의 확인 범위를 구분하고, ±log(1.10) 단위를 수정했다.
- 무역 partner 비중은 원시 derived 값에 맞춰 14.5582%·4.7515%로 표시했다.
- 인과 가설 미검증·최종 Gate 미채택을 표지·결론·노트에 명시했다.

## 2026년 11월 13일 문헌·측정계보 보완

최신 발표파일은 `deliverables/최종_연구발표_문헌보완.pptx`다. 기존 `deliverables/최종_연구발표.pdf`는 화면 본문이 같은 native PDF로 유지한다. 초기 PPTX와 최초 검증 receipt도 비교 기록으로 보존했다.

13·14·24장의 발표자 노트와 원고에 기존 200-family/넓은 IPC B, any-APP 및 공통 최초 피인용 공보 귀속, 새 WO 100-family/main-group과 APP 내 대표공보, family footprint의 별도 측정 및 β 미재추정을 명시했다. 4·37장과 참고문헌은 11월 13일 제공 원문 감사에 맞춰 Gao의 2026년 6월 85쪽 PDF, Zhang·Canlei Liu·Runjuan Liu와 Liu·Ruan·Zheng을 통합하고 He·Lyu의 간접 자본·인력 지표를 명시했다. 주장·근거표와 Q&A도 동기화했다.

개정 검증은 `.build/notes_revision_verification.json`과 `.build/validation_문헌보완.json`을 따른다. 본문 38장 XML은 무작위 추적용 creationId와 관계ID를 연결대상으로 정규화한 뒤 동일했고, 차트 7개 XML은 원시 해시가 같았다. PNG 38장의 SHA256과 기존 native PDF SHA256도 모두 일치했다. PDF 38페이지를 확인했다. 필수 노트 13·14·24·4·37장의 내용 검사를 통과했다. 재개 후 GUI나 COM을 다시 호출하지 않았다.

측정계보·문헌감사 상세문단은 질의응답용 보충을 포함한다. 본문 시간에는 각 장의 주된 설명과 핵심 결론을 말하고, 중복되는 계보 전문과 전체 근거 URL을 반복 낭독하지 않는다.


## 최종 발표시간 정정

첫 장 발표자 노트·발표원고·본문 원천의 “본문 권장시간은 38분 45초”를 동기화했다. PPTX에서 텍스트가 바뀐 발표자 노트는 1장뿐이며, 나머지 37장 노트와 결론은 같다.

최종 PPTX: `deliverables/최종_연구발표_시간정정.pptx`, 225,105바이트, SHA256 `e4dc2a000a6c27e028663892b0c43ea41fee1d582f0c24f3d69dd3219e35ef20`. 기존 native PDF는 292,163바이트, SHA256 `fd7092de62ef806a0f48356aaa557b8f1993afab51a169a88005059491478167`로 유지한다.

`.build/time_revision_verification.json`에서 추적ID·관계ID를 정규화한 본문38장 XML, 차트7개 XML, PNG38장 해시의 동일성과 PDF38페이지·기존 PDF 해시 유지를 확인했다. `.build/validation_시간정정.json`은 패키지·레이아웃·차트·재import 검증 통과 기록이다. `verify_time_revision.py`와 `finalize_time_metadata.py`를 보존했다. 이번 정정에는 GUI/COM을 호출하지 않았다.
