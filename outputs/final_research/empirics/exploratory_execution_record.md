# 추가 반증분석의 사전 실행기록

기록일: 2026-11-12. 이 파일은 아래 새 계산을 실행하기 전에 작성했다. 원 결과(후보창 ALL −0.0806645, APP −0.0499468), 2013–2016 학습→2017 holdout 실패, H01L 민감도는 이미 읽었다. 따라서 이번 분석은 기존 결과를 본 뒤 선택한 탐색이며 사전등록·독립 재현자료·확증분석이 아니다. 유의한 모형을 고르지 않는다. 모든 지정 결과와 실패를 보존한다.

자료는 기존 WO 국제특허 신청인주소 집계 5 IPC×5국×84개월, 결과는 log(1+family count)다. B는 2013–2017 표본 인용 미국비중 ALL/APP이며 처치량이 아니라 효과수정변수다. B의 당시 정보 이용가능성, 측정오차·모집단 정합성은 해결되지 않았다. 독립 기술지지점은 5이며 가족·인용 중첩으로 5개 독립 cluster도 보장되지 않는다.

고정 연산자: 각 월에 CN의 log결과에서 US/JP/KR/DE 동일가중 평균을 빼고, intercept와 B/0.10으로 IPC 5개 횡단면 OLS 기울기를 계산한다. 원 후보창 2018-12–2019-04, 원 기준 2017 월평균을 유지한다. 모든 수치는 인과추정치가 아닌 상대 투영대조다.

실행할 반증:
1. 동일한 후보창의 기준을 2017년 동일 calendar월(1·2·3·4·12월)로 바꾼 기술적 차이를 원기준과 대조한다. 연속 24개월 전 창 2016-12–2017-04도 모두 보존한다. 2017 동일월 기준은 1월–4월의 간격이 2년, 12월은 1년임을 표시한다. 전기간 pre2013–17 calendar월 평균 및 IPC별 계절진폭·48개월학습/2017검증 오차도 계산한다. 어떤 기준도 정답 반사실로 채택하지 않는다.
2. JP/KR/DE를 pseudo-China로 바꾼다. (a) 5국 내 focal국 대 나머지4국 평균의 완전대칭 연산자, (b) 모든 focal국 대 US의 공통앵커 연산자를 함께 기록한다. 전자는 CN을 donor로 포함하고 국가대조들이 대수적으로 종속됨을 밝힌다. 공식 무처치군 검정·배정기제 randomization p값으로 부르지 않는다.
3. 2013–17 안에 완결되는 5개월 가짜창을 계산한다. 주비교는 원기준과 같은 기하: 가짜창 시작 k에서 [k−23,k−12]의 12개월 기준과 [k,k+4]의 5개월 창을 대조한다(중간 11개월 간격). 2014-12–2017-08의 시작 33개를 전부 보존한다. 보조비교는 즉시 이전12개월 기준으로 2014-01–2017-08의 시작44개다. 원사건과 같은 Dec–Apr 계절의 시작 2014-12/2015-12/2016-12를 별도 표시한다. 창이 겹치고 공통사건이 있어 독립표본·공식 귀무분포가 아니다. 원계수의 기술적 순위만 계산한다.
4. theta_observed = target + bias라는 조건부 산술에서 허용 |bias|≤kappa 격자 0, .025, log1.05, log1.10, .15, .20, .30과 각 수치의 부호·5%/10% 크기 경계를 계산한다. fixed-B와 유효 공분산이 미확정이므로 이를 partial identification/HonestDiD CI라고 부르지 않는다. B를 ALL→APP로 바꾸는 차이는 측정민감도이며 오차의 확률분포가 아니다.
5. pilot simulation: 사전 60개월 월별 상대기울기에서 calendar월 평균+선형추세를 제거한 잔차를 사용한다. 12개월 원형 block bootstrap과 Gaussian AR(1)을 각각 가정한 무효과 가상 28개월(12개월 기준+11개월 간격+5개월 후보창)을 생성한다. 잔차배율 .5/1/2, AR rho 0/.5/.8를 모두 보고한다. 학습/독립평가 난수열을 분리하여 5% 양측 |대조| 임계값을 simulation으로 보정하고 size를 별도 MC표본에서 점검한다. 정규근사 1.96·IID표준오차의 size 실패도 기록한다. 대안은 log1.05·log1.10 per +10pp B를 분리하며, 80% 검정력 MDE는 양·음 방향 모두에서 작은 검정력을 기준으로 한다. 후보창에 고정 shift를 더하는 가상모형은 실제정책효과·유효표본·정책사건 수의 검정력이 아니다. 사전추세 모형 실패 때문에 파일럿 설계도구로만 해석한다. IPC 독립 또는 G=5 cluster 점근가정을 사용하지 않는다.

유효한 인과추론·원가설완료 판정은 하지 않는다. 기존 DB 재조회·원장·state 변경 없이 이 디렉터리에 코드/JSON/표/메모만 쓴다.
