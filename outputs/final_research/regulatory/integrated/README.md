# 규제표 통합본

2026-11-13. 기존81행표에 추가22행 후보문언 감사를 ID로 결합한 최신사본이다. 앞27개원본열은 그대로 보존했다. 이전파일/분모/심사/Gate를 덮어쓰지 않는다.

원41행 전부가 이제 적어도 일부후보ECCN문언의 직접열람근거를 갖는다. 그41개는 모두 **적용미확인**이다. 전체47은 부분문언42개, 직접ECCN미검토5개다. 후보조문검토는 전수규제/개정/거래요건의 감사가 아니다. **미통제(확인), 신규China-binding, 청정완전월의 확인은 모두0**이다. 이는 실제대상이 없다는 뜻이 아니라 확인에 충분한 증거가 없다는 뜻이다.
