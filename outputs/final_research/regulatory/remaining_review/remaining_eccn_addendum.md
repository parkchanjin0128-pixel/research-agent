# 잔여행 후보 ECCN 문언 검토 추가자료

2018-01-01 연간 CCL의 실제 해당 단락과 2018-10-24 개정지시 41의 4D001 문언을 읽고 만든 제한적 추가자료이다. 기존 데이터셋·overlay·coverage summary·과거 심사/Gate는 변경하지 않았다. 문서검색 hit를 검토 근거로 쓰지 않았다. 추출파일 전문과 실제 검토범위는 다르다.

선택 후속사건 일부 연결 6/미확인 41은 round2 사건 링크의 분모이며, 전체 47행의 현재 미통제 여부는 모두 미확인이다. 이번 22행은 원41 중 직접 ECCN 미검토 17와 기존 신경메모 5에 해당한다. 후보 문언을 읽었다는 뜻이며 후보 충족·미충족, 미통제 또는 감사창 추가제한은 확정하지 않는다. 모든 ECCN·모든 개정 연결 검토가 아니고 cutoff도 확정하지 않았다. 독립 검증·심사는 대기 상태다.

## 확인된 경계

- 4D001/4D994는 일반 AI·번역·전문가시스템·시각화·BCI SW 전체를 통제하는 문언으로 읽을 수 없다. 실제 지원 장비·개발/생산/사용 목적·특별설계/수정 관계를 특정해야 한다. 반대로 범용 기술명만으로 모든 관련 SW가 미통제라고 결론내릴 수도 없다.
- 2018-10-24 지시41은 4D001.b.1 APP를 15WT로 재기재하며 a의 특정 장비/SW 개발·생산 연결은 계속 요구한다. 1월판 b.1은 8WT이다. 이 조건부 변경을 22행 전체의 규제완화로 집계하지 않는다.
- 3A001.e.1/3A991.j의 셀과 배터리 제외, 5A001.b.6의 700bit/s 미만 음성코딩, 7D004의 특정 비행제어 소스와 일반 task scheduling 제외, 9D103/7A005의 당시 ITAR 교차참조는 서로 다른 경계다. 다른 관할 또는 다른 ECCN이 없다는 뜻이 아니다.
- Biomaterials라는 명칭은 1C351/353/991의 병원체·서열·독소·제형 요건을 입증하지 않는다. neural network IC라는 전자 품목 명칭도 생물학적 신경 인터페이스 전체와 동의어가 아니다.
