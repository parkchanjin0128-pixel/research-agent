# PDF 조판 QA

검토일: 2026-11-13. 마지막 조판은 `build_manifest.json`과 `completeness.json`의 입력·PDF 해시를 기준으로 한다.

## 확인 범위

- A4 22쪽 전부를 Poppler 100dpi PNG로 렌더해 contact sheet에서 확인했다.
- 본문·자료표·조달표·측정 경계·월별 기울기·조건부 MDE와 부록 수식을 145dpi 확대 화면으로 확인했다.
- Malgun Gothic 한글, SimSun 중국 기관·제품명, Segoe UI Symbol 대체 글꼴을 등록했다. 입력 문자별 지원 검사에서 누락은 0개다.
- PDF에서 추출한 텍스트와 입력 문단·표셀·목차·서지를 대조했다. 최종 서지 갱신을 포함한 290개 검토 항목이 모두 포함되었다. 페이지를 넘어가는 문단은 머리말·꼬리말을 제거한 본문 연결문에서 검사했다. `原문`은 출력에 없고, replacement character도 없다.
- PDF의 목차·외부 출처 링크 주석은 55개다. 문서 목차의 페이지 번호와 PDF 북마크를 생성했다.
- 전체 페이지 문자 bounding box를 검사했다. 설정한 안전영역 밖 문자는 0개였다. 이 검사는 시각 확인을 보완하며 대체하지 않는다.

## 공백·잘림·표 분리

- 공백 페이지는 없다. 표지·초록·목차는 각각 독립 페이지다. 본문 결론 뒤 부록과 참고문헌은 새 페이지에서 시작한다. 마지막 참고문헌 페이지의 잔여 공백은 분량에 따른 것이다.
- 국가연결률 그림의 높이를 조정해 첫 초안의 도표 단독 페이지 공백을 줄였다. 마지막 문헌 갱신 후 해당 그림은 11쪽 본문 뒤에, 24개 기술 경계 그림은 12쪽 본문 앞에 위치한다. 완결된 그림과 설명을 함께 유지하므로 11쪽 아래에 잔여 공백이 있다.
- 표 5개 모두 한 쪽에 유지했다. 행을 중간에서 나누지 않았으며, 표 제목에 해당하는 앞 절 제목이 별도 페이지에 남지 않도록 했다.
- 본문과 중국어 이름, 양·음 기호, 그리스문자, 수식 연산자, 표·그림의 축과 범례에서 잘림·검은 상자·겹침을 발견하지 못했다.
- 부록 A의 표시식은 입력 식의 모든 항을 유지하고 줄바꿈만 추가했다. 인덱스의 원문 표기와 식의 설명을 보존했다.

## 도표의 해석 표시

- R&D 도표는 명목 연간 공표액과 비중이다.
- 인용쌍 국가연결률과 원 피인용 공보/family footprint의 다른 측정대상을 구분했다.
- 24개 기술의 경계는 국가미상에 대한 조건부 산술 경계이며 표본오차 신뢰구간이 아니라고 표시했다.
- 월별 기울기는 사전 B 10%p당 상대 log(1+건수)의 기술통계이며, 후보창은 인과·청정 의사결정창으로 검증되지 않았다고 표시했다.
- 80% MDE의 단위는 로그단위/10%p B다. 정상 잔차·고정 B 조건부 진단이고 실제 정책효과의 MDE가 아니라고 표시했다.

최신 입력에 추가 수정이 생기면 PDF·전체 페이지 렌더·텍스트 대조·이 기록의 숫자를 다시 갱신해야 한다.
